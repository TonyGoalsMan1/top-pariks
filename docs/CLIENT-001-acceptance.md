## Подтверждённые проверки

- Чистый внешний сеанс Edge с эмуляцией iPhone 13 открыл витрину без входа в GitHub. Проверены три синтетических товара, каталог без горизонтального переполнения и тестовое оформление. На оформлении доступен только офлайн-метод COD. Стенд возвращает метатег noindex. Проверка на физическом смартфоне и в отдельной мобильной сети не проводилась.
- Публичные маршруты панели и входа вернули 403 как при обычном открытии, так и при запросе автологина Playground. REST-страница текущей учётной записи вернула 401. Публичная копия развернулась из тестовых фикстур, без рабочей базы. Синтетические товары явно помечены, исходные поля заказа пусты, отправка почты отключена.
- Точные версии проверены по работающему гостевому стенду и локально восстановленной учебной копии. WordPress 7.1.5 и WooCommerce 11.3.1 сверены с официальными публикациями. [WordPress](https://wordpress.org/news/2026/11/wordpress-7-1-5-release/) · [WooCommerce](https://developer.woocommerce.com/2026/11/19/woocommerce-11-3-1/)
- Скачанный ZIP совпал с контрольной суммой GitHub Actions, внутренний tar.gz — с опубликованной SHA-256. Архив, контрольные суммы и материалы находятся в защищённой папке владельца Windows. Учебная копия восстановлена в отдельной базе с портом только на loopback. Проверены вход и список товаров. Для демонстрации подготовлен один синтетический заказ. Инструкция и пароль доступны владельцу локально, пароль хранится с Windows DPAPI.
- Пустой CSV содержит 34 колонки с теми же именами и порядком, что и проверенный импорт STORE-005. Повторный импорт реального ассортимента ожидает заполненный файл заказчика.
