# STORE-002 · Проверка личного кабинета TOP-PARIKS

## Сценарии

- Гость открывает `/my-account/` и форму восстановления пароля. Регистрация с вымышленным адресом электронной почты и собственным паролем открывает кабинет покупателя.
- Покупатель выходит, снова входит, сохраняет имя в профиле и платёжный адрес. В кабинете открываются список заказов, карточка своего заказа и раздел загрузок. После выхода детали заказа гостю недоступны.
- WooCommerce сформировал ссылку для сброса пароля. В отдельном контейнере письмо перехвачено локально, пароль изменён по ссылке, вход с новым паролем подтверждён. В Preview отправка внешней почты подавляется, поэтому получить письмо из Preview нельзя.
- В сессиях гостя и покупателя счётчик корзины отразил AJAX-добавление, изменение количества и удаление последней позиции. Последовательность значений — `0 → 1 → 2 → 3 → 0`.
- В Chromium проверены 320, 359, 390, 560, 768, 820, 1024 и 1440 CSS-пикселей. Формы и подразделы кабинета помещаются по ширине. Номер тестового заказа виден и открывает детали в эмуляции iPhone 13. Физический iPhone с Safari в прогоне не использовался.

## Ограничения Preview

`/checkout/` перенаправляет в корзину, кнопка оформления скрыта, классическое AJAX-оформление с действительным nonce отклоняется, Store API checkout отвечает `403`. Посетителю недоступны платёжные шлюзы. Сохранены проверка тестового SKU, подавление исходящей почты, блокировка внешних запросов WordPress и запрет индексации.

Blueprint прошёл проверку схемы. В локальном WordPress Playground проверены гостевые формы, регистрация, кабинет, история заказов, AJAX-добавление и блокировка checkout. Из-за сетевых ограничений окружения при запуске Playground архив WordPress 6.9.1 взят из образа Docker, WooCommerce 10.5.3 — из GitHub Releases, тема — из закреплённого в Blueprint коммита. Эти архивы подавались локально с сохранением настроек и PHP-кода Blueprint.

На отдельном Docker-стенде также прошли существующие `woocommerce-smoke.sh` и `mobile-ux-smoke.cjs`, включая гостевое оформление с тестовой офлайн-оплатой.
