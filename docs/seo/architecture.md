# SEO-001 · Архитектура каталога TOP-PARIKS

Карта использует пути ARCH-002 как ориентир. Публичные адреса привязываются к ID объектов после инвентаризации боевого магазина. Предложенные посадочные публикуются после сверки спроса в Яндекс Вордстате и Google Search Console, подтверждения ассортимента и проверки пересечения поисковых интентов.

Категории реализуются через `product_cat`, значения фильтров через глобальные WooCommerce-атрибуты при наличии данных. Материал и длина могут одновременно классифицировать товар. Выбрать один устойчивый путь хлебных крошек карточки, предпочтительно через материал. Фильтры каталога: материал, длина, цвет, текстура, размер, тип основы, цена и наличие. Первые шесть брать из нормализованных атрибутов, цену и наличие из WooCommerce. Названия для покупателя на русском, единицы измерения и значения согласовать с контент-командой. Дополнительные комбинации по умолчанию остаются фильтрами.

Для новых slug использовать строчную латиницу, цифры и дефис, единый словарь транслитерации, стабильные имена без цены, сезона и акций. Проверять уникальность относительно страниц, товаров, таксономий и endpoints. Для новых публичных страниц использовать согласованные HTTPS, хост и завершающий слеш. Существующие slug и bases сохранять до согласования, ссылки получать через API WordPress и WooCommerce. Сортировку, параметры аналитики и фильтры не встраивать в ЧПУ карточки.

Карточка получает H1 из проверенного названия товара, Title из названия и бренда, Description из проверенных отличительных свойств. При совпадениях добавить подтверждённое отличие модели. Удалить из Description утверждения о фильтрах или данных, которых нет на опубликованной странице. Заголовки и первый экран согласовать с TOP Design до правок шаблона.

## План контента

1. Категориям дать короткое описание над или рядом с ассортиментом, далее критерии выбора и ссылки на смежные категории и инструкции. По одному основному коммерческому интенту на посадочную.
2. Карточки заполнить из карточки поставщика и WooCommerce: название, фотографии, состав, длина, оттенок, размер, основа, комплектация, рекомендации по уходу. Редактор сверяет поля, неизвестные значения пропускает. Цена, остаток и варианты выводятся WooCommerce.
3. FAQ собрать из реальных вопросов покупателей. Стартовые темы: как измерить обхват головы, как сравнить оттенки, можно ли использовать нагрев, как ухаживать и хранить. Допуски по температуре брать из инструкции производителя. Условия возврата согласовать с ответственным за правила магазина.
4. Первая очередь статей: «Как измерить размер головы для парика», «Натуральные и синтетические парики: различия», «Как ухаживать за париком». Ссылки вести из статьи в релевантную категорию через описательные анкоры и обратно из материалов о выборе. Целевые показатели после публикации: показы, клики, CTR и переходы в карточки по посадочной и интенту.
