# STORE-003 · Восстановление витрины

Тема уже содержит фирменный шаблон главной, шаблон каталога и ссылки корзины и аккаунта на настройки WooCommerce. В репозитории теперь есть ручная настройка для тестового WordPress. Она использует существующие опубликованные страницы по назначению или по путям `home`, `shop`, `about`, `delivery`, `contacts`, `cart`, `checkout`, `my-account` и создаёт недостающие. Адреса переиспользуемых страниц сохраняются. Содержимое страниц, товары и заказы остаются в базе. Если у существующей служебной страницы отсутствует нужный блок или шорткод, админка покажет её ID и подскажет, что добавить.

Настройка назначает статическую главную, четыре страницы WooCommerce и основное меню темы. Она сохраняет существующую структуру постоянных ссылок или выбирает `/%postname%/`, если использовалась простая структура. WooCommerce по-прежнему отправляет из пустого оформления заказа обратно в корзину.

## InfinityFree после согласования публикации

1. В панели InfinityFree откройте именно `top-pariks-test.freehosting.dev`. Сохраните копию базы через phpMyAdmin и копию каталога `wp-content/themes/top-pariks` через FTPS. Проверьте в админке, что активны тема TOP-PARIKS и WooCommerce.
2. Возьмите `top-pariks.zip` из согласованной ревизии. В **Внешний вид → Темы → Добавить → Загрузить тему** загрузите ZIP и подтвердите замену установленной версии. Если загрузка ZIP недоступна, распакуйте его локально и загрузите файлы в тестовый каталог `wp-content/themes/top-pariks` через FTPS или файловый менеджер. Параметры подключения описаны в [STAGE-002B](STAGE-002B.md).
3. Войдите как администратор тестового WordPress. В **Инструменты → Настройка витрины** нажмите **Настроить витрину**. Если WordPress сообщает о конфликте, проверьте указанную страницу, сохраните её содержимое, устраните конфликт и повторите запуск. Для корзины и оформления поддерживаются штатные блоки и шорткоды. Для личного кабинета используется `[woocommerce_my_account]`.
4. Откройте **Настройки → Постоянные ссылки** и нажмите **Сохранить изменения**, чтобы WordPress применил серверные правила. Если WordPress покажет правила для недоступного на запись `.htaccess`, внесите их через файловый менеджер, сохранив остальные правила. При установке в подкаталоге используйте правила, которые показывает админка этого сайта.
5. Проверьте **Настройки → Чтение**, назначения магазина и служебных страниц в **WooCommerce → Настройки** и расположение «Основное меню». Проверьте дополнительные ссылки, которые были в меню до настройки. На странице «Контакты» добавьте подтверждённые данные магазина через редактор. Для восстановления после публикации используйте копии темы и базы, согласовав восстановление базы с учётом любых записей, сделанных после резервного копирования.

## Проверка в Safari на iPhone

1. В приватной вкладке откройте корень сайта. Проверьте заголовок «Парики для вашего образа», мобильное меню и переход в каталог через кнопку на главной.
2. Из меню последовательно откройте главную, каталог, «О компании», «Доставка и оплата» и «Контакты». Убедитесь, что открывается нужная страница без 404 и циклических перенаправлений. В пустом магазине каталог покажет сообщение TOP-PARIKS. Если на стенде есть товары, проверьте их отображение, сохранив имеющиеся записи.
3. Откройте «Войти» и «Корзина». Проверьте форму аккаунта и состояние корзины. При наличии тестового товара добавьте его и откройте оформление. Достаточно увидеть форму оформления без отправки заказа.
4. Запустите настройку повторно в админке. Сравните ID назначенных страниц, количество страниц и пункты меню. Повторите переходы после второго запуска.
