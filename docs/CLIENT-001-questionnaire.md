# Анкета заказчика TOP-PARIKS

Заполните согласованные сведения. Для открытых вопросов укажите ответственного и срок. Пароли, токены и данные клиентов через эту анкету передавать не нужно.

| Блок | Что предоставить | Ответ |
| --- | --- | --- |
| Продавец | Юридическое и публичное название, реквизиты и текст раздела «О компании». Кто утверждает публикацию? | |
| Контакты | Публичные телефон, почта, адрес или порядок записи, часы работы и контакт для возвратов. | |
| Ассортимент | CSV с артикулами, категориями, ценами, остатками и вариациями. Материал, длина, цвет, размер, тип основы, уход. Какие модели вывести на главную? | |
| Медиа | Логотип, баннер и фото товаров. Подтверждение прав, соответствие файлов артикулам, подписи и альтернативные тексты. | |
| Оплата | Валюта, способы оплаты, провайдер, правила возврата денег и ответственное лицо. | |
| Доставка | Регионы, способы, перевозчики, сроки, стоимость, самовывоз и условия бесплатной доставки, если применимо. | |
| Документы | Утверждённые тексты об оплате, доставке, возврате и обработке данных. | |
| Домен и почта | Кто управляет DNS, какой хостинг выбран, с какого доменного адреса отправлять уведомления, кто проверяет тестовые письма? | |
| Миграция | Выгрузка старых URL или sitemap, адреса важных страниц, доступные данные Вебмастера, окно переключения и ответственный за откат. | |
| Доступы и сопровождение | Кто ведёт товары и заказы, кто отвечает за обновления, резервы и восстановление? | |
