# Массовый импорт каталога WooCommerce

[CSV-шаблон](store-005-catalog-template.csv) содержит только синтетические строки. В файле UTF-8 с разделителем «запятая» первые строки создают простой товар и родительскую вариативную модель. Две следующие строки создают варианты. Столбец Published со значением -1 сохраняет основные карточки черновиками.

## Подготовка

- Оставьте артикулы уникальными и неизменными, в том числе у вариаций. Храните исходный экспорт перед обновлением.
- Для фильтров каталога заранее заведите глобальные атрибуты «Материал», «Длина», «Цвет» со слагами material, length, color. В шаблоне размер и тип основы даны как локальные характеристики карточки. При необходимости заведите и их глобально до ввода ассортимента.
- В поле Categories укажите иерархию через знак >. Вариация ссылается через Parent на артикул родителя.
- Замените atelier-demo-photo.webp именем уже загруженного изображения. При использовании HTTPS-адреса проверьте разрешение на скачивание, права на изображение и доступность URL для сервера. Первая фотография становится основной, следующие входят в галерею. Alt задаётся в медиатеке.
- Оставьте английские системные заголовки. В колонках Meta: atelier_seo_title и Meta: atelier_seo_description укажите метаданные для темы. Эти столбцы можно сопоставить вручную со свойствами метаданных в интерфейсе импорта. Пустые поля метаданных используют обычный заголовок и описание.

## Создание и обновление

1. На изолированной установке откройте **Товары → Все товары → Импорт**. Для новых артикулов оставьте «Обновить существующие товары» выключенным.
2. Укажите CSV, проверьте сопоставление всех полей, включая пять атрибутов и связи Parent. Запустите импорт. Убедитесь, что вариации принадлежат нужной модели и имеют собственные цены и остатки.
3. Для повторной загрузки существующих строк включите «Обновить существующие товары». WooCommerce сопоставляет их по SKU или ID. Используйте исходные SKU и проверьте отчёт обновления. Новые SKU выделяйте в отдельный файл и создавайте отдельным импортом.
4. Сверьте карточки, цены, остатки, категории, фильтры и фото на тестовом сайте. Перед массовой рабочей загрузкой сохраните резервную копию и согласуйте состав изменяемых столбцов. Публикуйте только проверенный каталог.
