# TOP-PARIKS · краткая инструкция заказчику

Гостевая витрина показывает тестовые товары. Для работы с WordPress Admin используйте отдельную учебную копию вместе с владельцем. Для неё подходят только синтетические данные.

| Задача | Что сделать в WordPress |
| --- | --- |
| Добавить товар | **Товары → Добавить**. Заполните название, уникальный артикул, описание, цену и остаток. Выберите категорию. Сохраните черновик, проверьте предпросмотр и опубликуйте. Для модели с цветами или размерами выберите вариативный товар. |
| Поменять цены и фото | **Товары → Все товары → Изменить**. В «Данных товара» укажите обычную и при необходимости акционную цену. Замените «Изображение товара» и обновите галерею. У вариативной модели проверьте цену, фото и остаток каждой вариации. |
| Обработать заказ | **WooCommerce → Заказы**. Откройте заказ, сверьте позиции и способ доставки. До смены статуса оплаты проверьте подтверждение у провайдера. Сохраните новый статус. |
| Редактировать страницы | **Страницы → Все страницы**. Откройте нужный раздел, измените текст, проверьте предпросмотр и нажмите «Обновить». |
| Редактировать главную | **Внешний вид → Настроить → Главная страница и контакты**. Замените баннер, заголовки, подпись кнопки и публичные контакты. Логотип меняется в «Свойствах сайта», меню — в «Внешний вид → Меню». Звезда в списке товаров добавляет модель в подборку на главной. |

Для передачи каталога оставьте системные заголовки CSV на английском. Начните с пустого бланка и используйте уникальные SKU. Начните с нескольких черновиков. При повторной загрузке используйте те же SKU и включите обновление существующих товаров.
