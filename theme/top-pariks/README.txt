TOP-PARIKS Atelier — WordPress theme, version 1.0.0

INSTALLATION
1. WordPress admin > Appearance > Themes > Add New > Upload Theme.
2. Select top-pariks.zip, install and activate.
3. Home page uses front-page.php automatically.
4. Install/activate WooCommerce and complete its setup wizard.
5. Add products; the demo product cards will be replaced with live WooCommerce products.
6. Appearance > Menus: create and assign a menu to 'Основное меню'.
7. Settings > Permalinks: choose Post name.

IMPORTANT
- Cropped visual assets are extracted from the user-provided reference mockup solely for prototype demonstration. Replace with original licensed imagery before launch.
- Demo product names/prices and phone number are NOT verified business data.
- 'Избранное' is a visual link only until a wishlist extension is installed.
- Payments, shipping, customer data compliance and real SEO migration require separate configuration.
- No real transactions should be tested without configuring a payment gateway and secure hosting.
- WordPress Playground may be temporary. Export the site before closing/resetting.
