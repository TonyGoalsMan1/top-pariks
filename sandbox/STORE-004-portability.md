# Перенос демонстрации TOP-PARIKS Atelier

Пакет содержит WordPress, тему, WooCommerce, локализацию, медиа и полную SQL-копию синтетической витрины. Конфигурация с ключами исходной установки исключена. Restore создаёт новую конфигурацию. Тестовые ограничения на почту и платежи действуют в новой копии.

Понадобятся Docker Compose и Bash. В каталоге распакованного пакета задайте уникальное имя проекта, свободный порт и новый пароль базы.

~~~sh
export ATELIER_RESTORE_PROJECT=atelier-restore-review
export ATELIER_DEMO_PORT=8086
export ATELIER_DEMO_DB_PASSWORD="$(openssl rand -hex 24)"
bash restore.sh
~~~

Откройте адрес из вывода. Скрипт проверяет хеши, отказывается использовать существующий проект и меняет адрес сайта штатным WP-CLI с поддержкой сериализованных данных. Для входа администратора назначьте новый пароль пользователю topqa через WP-CLI внутри восстановленного контейнера. Резервная копия предназначена для демонстрационных данных.

Обычный хостинг WordPress может использовать те же файлы и SQL. На целевом хосте потребуются собственная конфигурация базы и ключи, правила постоянных ссылок и замена адреса сайта. Перед коммерческой публикацией нужны утверждённые данные, реальные настройки хостинга и отдельная приёмка. После развёртывания WordPress использует собственные файлы и базу.
