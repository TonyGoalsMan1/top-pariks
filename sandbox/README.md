# Тестовый магазин TOP-PARIKS

Понадобятся Docker с Compose v2, Bash, curl и sha256sum (из GNU coreutils). При первом запуске требуется доступ к Docker Hub и GitHub Releases. Используются WordPress 6.9.1 (PHP 8.3), MariaDB 11.4.10, WP-CLI 2.12.0 и WooCommerce 10.5.3.

Из корня ветки `arch/002-test-environment` выполните:

```sh
./sandbox/start.sh
```

Откройте [http://localhost:8080/](http://localhost:8080/). Тема читается из `theme/top-pariks`, поэтому правки исходников появляются на стенде без переустановки темы. Docker хранит тестовую базу и WordPress в томах. Повторный запуск сохраняет заказы и не создаёт копии первоначальных товаров. Команда `docker compose down` останавливает стенд с сохранением этих данных.

Для работы с настройками можно сгенерировать новый пароль локальному администратору `topqa`. Команда выведет пароль в терминал:

```sh
docker compose exec --user www-data wordpress php /tmp/top-pariks-wp-cli.phar user reset-password topqa --show-password
```

Если агенты работают на одном Docker-хосте, каждому нужны отдельное имя проекта Compose и порт. Например:

```sh
COMPOSE_PROJECT_NAME=top-pariks-design TOP_PARIKS_PORT=8082 ./sandbox/start.sh
COMPOSE_PROJECT_NAME=top-pariks-design docker compose down
```

Указывайте одинаковое имя проекта при запуске и остановке. Данные и заказы хранятся отдельно для каждого проекта.

## Проверка в Safari на iPhone

Подключите iPhone и компьютер с Docker к одной доверенной частной сети Wi‑Fi. Найдите LAN IP компьютера. В следующем примере замените `192.168.1.42` на этот адрес:

```sh
TOP_PARIKS_BIND=192.168.1.42 TOP_PARIKS_URL=http://192.168.1.42:8080 ./sandbox/start.sh
```

В Safari откройте адрес из `TOP_PARIKS_URL`. Убедитесь, что брандмауэр компьютера разрешает входящие соединения из локальной сети на порт 8080. Для другого порта укажите также `TOP_PARIKS_PORT` и подставьте его в URL. Облачный Docker обычно недоступен из домашней Wi‑Fi сети. Для этой проверки запустите стенд на компьютере рядом с iPhone. Используйте гостевой сценарий. Доступ по HTTP предназначен для тестовых данных внутри доверенной сети. После проверки остановите стенд или верните привязку к loopback командой `./sandbox/start.sh` без переменных.

1. На главной странице откройте «Весь каталог». Убедитесь, что видны модели Atelier и Studio, помеченные «ТЕСТ».
2. Откройте модель Atelier. Добавьте одну единицу в корзину и перейдите по ссылке просмотра корзины. Проверьте название, количество и итог $19.00.
3. Перейдите к оформлению заказа. Введите вымышленные данные, приведённые ниже. Выберите **Test only — offline payment** и отправьте заказ один раз.
4. Проверьте страницу подтверждения, номер заказа и итог $19.00. Карта и доставка для виртуального тестового товара не требуются.

| Поле | Значение |
| --- | --- |
| Имя и фамилия | Test Customer |
| Email | shopper@example.test |
| Телефон | +1 415 555 0100 |
| Страна и штат | United States / California |
| Адрес | 123 Test Street |
| Город и индекс | San Francisco / 94105 |

Стенд использует гостевой checkout и классические страницы корзины и оформления. Тестовые товары виртуальные. Исходящая почта подавляется, внешние HTTP-запросы из WordPress заблокированы через его HTTP API, а на витрине доступен только офлайн-метод оплаты. Здесь проверяется создание заказа. Для сценариев доставки, платёжных интеграций и Checkout Blocks нужны отдельные тестовые настройки.

## Отчёт ARCH-002

- 21 ноября 2026 года выполнен чистый запуск Docker Compose на отдельном наборе томов. Подтверждены активация темы и WooCommerce и создание двух товаров и четырёх тестовых категорий.
- В Chromium проверены главная, категория, каталог, карточка Atelier, корзина с одной позицией и гостевой checkout. Настольный режим 1440 × 900 создал заказ №14, эмуляция iPhone 13 создала заказ №15. Оба заказа приняты со статусом `processing`, методом `cod` и итогом $19.00. Физический iPhone и Safari в этом прогоне не использовались.
- После `docker compose down` и повторного запуска оба заказа сохранились. Повторный запуск оставил два тестовых товара и четыре категории. PHP-файлы темы и стенда прошли синтаксическую проверку.
- Все 20 файлов темы совпадают с исходным ZIP побайтно. В том числе сохранена пустая строка в конце архивного `functions.php`, которую отмечает `git diff --check`.
