# DESIGN-001 · Мобильная витрина TOP-PARIKS

Основа — `arch/002-test-environment` на коммите `87ee0c1`. Проверка проведена на отдельном локальном стенде `top-pariks-design` с тестовыми товарами и офлайн-оплатой.

## Аудит и изменения

| Область | До | После |
| --- | --- | --- |
| Шапка | Строка ссылок с горизонтальной прокруткой, кнопки поиска и корзины обозначены символами | Мобильное меню по кнопке «Меню», подписанные поиск и корзина, цели касания от 44 px. Escape закрывает меню и возвращает фокус. При отключённом JavaScript ссылки остаются доступны. |
| Первый экран | Принудительные переносы и общий текст о стиле | Короткое предложение о натуральных и искусственных моделях, видимый переход в каталог, тёплая палитра и существующая фотография. |
| Поиск и категории | Поисковый запрос терялся в поле после перехода, категории доступны с главной | Запрос сохраняется. Каталог, результаты поиска и архивы товаров показывают ссылки на заполненные категории верхнего уровня. Активная категория отмечена. |
| Товары | Разнородные карточки главной и WooCommerce | Одинаковые пропорции изображений и стили кнопок, две колонки на мобильных и четыре на настольных экранах. Названия и кнопки переносятся по ширине карточки. |
| Узкие экраны | Поля автора и email в форме отзывов выходят за пределы экрана при ширине 320 px | Поля ограничены шириной формы. Стиль поисковой формы привязан к классу компонента, чтобы избежать совпадения с классом `search` у `body` WordPress. |

Шаблоны и маршруты WordPress и WooCommerce используют существующую интеграцию. В каталоге сохранены сортировка, карточки товаров и действия WooCommerce. Корзина и оформление используют классические страницы стенда.

## Результаты проверки

- Chromium 156 и Playwright 1.65.1, эмуляция iPhone 13 (390 × 844) и настольный экран (1440 × 900). Проверены навигация, поиск с результатами и без них, сортировка по цене, категория, товар, корзина и гостевое оформление.
- Заказы №16 и №17 на локальном стенде подтверждены в WooCommerce. Оба имеют статус `processing`, метод `cod` и итог $19.00.
- На ширинах 320, 360, 390, 768, 820, 821, 1024 и 1440 px на главной, в каталоге и карточке товара проверены отсутствие горизонтальной прокрутки документа и доступность навигации без JavaScript. Корзина и оформление дополнительно проверены при 320 px.
- `php -l` для всех PHP-файлов темы, `node --check` для скриптов и `git diff --check` прошли.
- Архив `DESIGN-001-before-after.zip` приложен к результатам задачи. Внутри восемь полноразмерных PNG с главной и каталогом до и после изменений на обоих разрешениях.

### Повторный запуск

Из корня репозитория выполните команды ниже. Тест создаёт два офлайн-заказа на локальном стенде с тестовыми товарами. Укажите путь к установленному Chromium.

```sh
COMPOSE_PROJECT_NAME=top-pariks-design TOP_PARIKS_PORT=8082 ./sandbox/start.sh
npm install --prefix /tmp/top-pariks-qa playwright-core@1.65.1
NODE_PATH=/tmp/top-pariks-qa/node_modules TOP_PARIKS_URL=http://localhost:8082 \
  CHROMIUM_PATH=/usr/bin/chromium node sandbox/mobile-ux-smoke.cjs
```

## Оставшиеся ограничения

- Физический iPhone и Safari в прогоне отсутствовали. Для проверки на устройстве используйте сценарий из [документации стенда](README.md).
- Тестовая база создаёт два виртуальных товара без фотографий. WooCommerce показывает заглушки и англоязычные системные подписи тестовой установки. Тест охватывает классическое оформление с офлайн-оплатой. Доставка, платёжные шлюзы и Checkout Blocks требуют отдельного стенда.
- Исходные фотографии темы остаются демонстрационными. Ссылка «Избранное» рассчитана на отдельное расширение. Часть информационных ссылок резервного меню ведёт на страницы, которые тестовая база не создаёт.
